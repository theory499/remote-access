Firebase web config (this desktop)

Paste the firebaseConfig snippet from Firebase Console → Project settings → Your apps → Web app, exactly as shown there. JavaScript object literal syntax (unquoted keys), the full const firebaseConfig = { ... }; assignment, single quotes, and trailing commas are all accepted. The wizard signs in anonymously and writes a test record to confirm everything works.

Don't have it yet? Click for setup steps.
  1. Create a project at console.firebase.google.com.
  2. Build → Authentication → Sign-in method → enable Anonymous.
  3. Build → Realtime Database → Create database.
  4. Realtime Database → Rules: paste the rules from and Publish.
  5. Project settings → Your apps → Add Web app, copy the config object.

Pair your phone

Scan this QR code from the Remote Desktop app on your phone. It contains the Firebase configuration for the platform your phone reads it on.

Anyone holding this image can configure a phone against your Firebase project. Treat it like a deployment key.
