# Proxia — Android client

Native Kotlin client that pairs with the desktop host over WebRTC,
configured at runtime from a QR code generated by the desktop wizard.
No `google-services.json` is needed at build time.

## Prerequisites

- JDK 17.
- Android SDK Platform 34 and Build-Tools 34.
- Gradle 8.x (the wrapper pins 8.14.3; first-time setup uses your
  system `gradle` to bootstrap the wrapper).
- A connected device or running emulator.

## Build and install

```sh
cd mobile/android
gradle wrapper --gradle-version 8.14.3   # one-time, generates ./gradlew
./gradlew installDebug
```

The first build downloads CameraX, ML Kit, Firebase, and webrtc-sdk
artifacts (~150 MB).

## How it works

1. On first launch the activity finds no stored config in
   `SharedPreferences` and opens `QrScannerActivity`.
2. The user scans the QR code shown in the desktop setup wizard.
3. The Android app parses the JSON payload, extracts the Android-specific
   fields (`apiKey`, `applicationId`, `projectId`, `databaseURL`),
   persists them, and initialises Firebase via
   `FirebaseApp.initializeApp(context, FirebaseOptions(...))`.
4. From the next launch on, the app goes straight to the pairing-code
   screen.

Tap **Change backend configuration** to clear the stored credentials
and re-scan.

## File map

| Folder / file | Role |
| --- | --- |
| `app/src/main/java/com/remotedesktop/RemoteDesktopApp.kt` | `Application` subclass, lazy Firebase init. |
| `app/src/main/java/com/remotedesktop/config/FirebaseConfig.kt` | Data class + QR payload parser. |
| `app/src/main/java/com/remotedesktop/config/ConfigStore.kt` | `SharedPreferences` wrapper. |
| `app/src/main/java/com/remotedesktop/ui/QrScannerActivity.kt` | CameraX + ML Kit QR scanner. |
| `app/src/main/java/com/remotedesktop/ui/MainActivity.kt` | Routes between QR scanner and pairing-code entry. |
| `app/src/main/java/com/remotedesktop/ui/RemoteControlActivity.kt` | Live session UI. |
| `app/src/main/java/com/remotedesktop/signaling/SignalingClient.kt` | Firebase Realtime Database wrapper. |
| `app/src/main/java/com/remotedesktop/webrtc/WebRTCClient.kt` | `PeerConnectionFactory` and peer connection. |
| `app/src/main/java/com/remotedesktop/input/*` | Encoder, surface controller, key mapper, pairing code. |
| `verify/` | JVM-only Gradle project that runs the platform-independent unit tests without an Android SDK. |

## Tests

```sh
# JVM-only (no Android SDK needed):
cd mobile/android/verify
gradle test --no-daemon

# Full unit tests (Android SDK required):
cd mobile/android
./gradlew test

# Instrumented tests (device or emulator required):
./gradlew connectedAndroidTest
```

The JVM verification suite covers `InputEventEncoder`,
`RemoteSurfaceController`, `PairingCode`, `SdpPayload`, and
`FirebaseConfig` — 36 tests at the time of writing.
